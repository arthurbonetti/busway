GPS real no celular (HTTPS)

Para o navegador do celular liberar geolocalização, abra o projeto via HTTPS público (não apenas localhost).

Resumo: rode local, exponha com túnel HTTPS, abra o link HTTPS no celular e permita localização.

Opção 1: Cloudflare Tunnel (grátis)

  1. Suba um servidor local na pasta do projeto.
  2. Abra um túnel HTTPS para a porta local.
  3. Use a URL https://... no celular.
# no projeto
python3 -m http.server 5500

# em outro terminal (com cloudflared instalado)
cloudflared tunnel --url http://localhost:5500

Copie a URL gerada pelo tunnel e abra no celular.

Opção 2: ngrok (grátis)

# no projeto
python3 -m http.server 5500

# em outro terminal (com ngrok instalado)
ngrok http 5500

Abra no celular a URL HTTPS exibida pelo ngrok.

Checklist rápido

  1. Usuário do tipo Motorista logado.
  2. Página Transmissão GPS aberta no celular.
  3. Permissão de localização concedida no navegador.
  4. Uma viagem ativa selecionada e botão Iniciar GPS real acionado.
No iPhone, use Safari. Em alguns Androids, mantenha a tela ativa durante o teste para evitar pausa do GPS.
